📖 这套系统是什么？

简单来说：它是一个「虚拟村级管理团队」。

传统农村管理靠村干部一人身兼数职。这套系统把管理工作拆分成 32 个专业 AI 代理，覆盖从「种什么」到「卖给谁」的全链条。

核心理念

你（村长/管理者）只需要提出问题和做决策，32 个 AI 代理会自动协作完成调研、分析、方案制定和执行跟踪。

你的使用方式

从提问到执行，只需 5 步
💬1. 提问今年种什么赚钱？

定价机制

定价公式：
  渠道终端价 = 成本价 x (1 + 目标毛利率) x 渠道系数

以草莓为例（成本 6 元/斤）：
  批发：6 x 1.5 x 1.0 = 9 元/斤    → 实际 15-20 元
  电商：6 x 1.5 x 1.8 = 16.2 元/斤 → 定价 29.9 元/500g
  直播：6 x 1.5 x 1.5 = 13.5 元/斤 → 定价 35.9 元/1kg
  采摘：6 x 1.5 x 2.5 = 22.5 元/斤 → 定价 60 元/人

系统自动检查：
  ✅ 毛利率 > 10% → 正常
  ⚠️ 毛利率 < 10% → 警告
  ❌ 售价 < 成本  → 阻断（需审批）

❓ 常见问题

Q: 需要什么前置条件？

安装 Claude Code CLI（需要 Anthropic API 密钥），Git，以及可选的 jq 和 Python。

Q: 我不懂技术，能用吗？

完全可以。只需要用自然语言描述你想做什么，比如"我想看看今年种什么赚钱"。

Q: 数据从哪里来？

土壤数据需要实际检测后录入；市场价格代理可以联网查询；天气数据可对接气象API；历史数据需逐步积累。系统越用越准。

Q: 一个人能管理吗？

可以。这就是设计初衷 — 1-2 人借助 AI 代理完成一个专业团队的工作。

Q: 能跟现有系统对接吗？

可以。代理的工具权限（Read/Write/Bash等）允许它们读写外部系统的数据文件。如果有 API 接口，可以通过 Bash 工具调用 curl 对接。
