## 二、店铺搭建指南

### 2.1 基础搭建清单

```yaml
开店准备：
  营业执照: 村集体/合作社名义
  食品经营许可证: 必须
  农产品合格证: 每批次
  品牌商标: R标优先，TM标可用
  质检报告: 第三方检测机构
  
  银行对公账户: 合作社账户
  快递协议: 至少2家快递公司
  
店铺装修：
  主图: 白底图 + 场景图 + 细节图 + 对比图 + 包装图（5张）
  详情页: 产地介绍 → 品质展示 → 规格说明 → 售后保障
  短视频: 15-30秒产品展示视频
```

### 2.2 产品上架公式

```
标题公式（淘宝/拼多多）：
  [品牌] + [核心关键词] + [规格/产地] + [卖点] + [适用场景]
  
示例：
  「XX村 有机草莓 新鲜现摘 1斤装 奶油草莓 当季水果 顺丰空运」
  
价格设置：
  ┌──────────────────────────────────────┐
  │ SKU设计（以草莓为例）：               │
  │                                      │
  │  试吃装 250g  → 19.9元（引流款）      │
  │  标准装 500g  → 35.9元（利润款）      │
  │  家庭装 1kg   → 59.9元（性价比款）    │
  │  礼品装 2kg   → 168元（利润款）       │
  └──────────────────────────────────────┘
```

## 四、客户服务标准

### 4.1 响应时效

| 场景 | 响应时间 | 处理时限 |
|------|---------|---------|
| 售前咨询 | <3分钟 | 即时 |
| 物流查询 | <5分钟 | 即时 |
| 售后投诉 | <10分钟 | 24小时内 |
| 退换货 | <1小时 | 48小时内 |

### 4.2 售后处理标准

```
收到投诉/差评 → 第一时间联系客户

  损坏/腐烂（物流问题）：
    ├── 损坏<30% → 退差价/补发部分
    └── 损坏>30% → 全额退款或重新发货
    
  品质不满意：
    ├── 确实品质问题 → 退款+道歉+优惠券
    └── 正常品质 → 解释说明+赠送小礼品
    
  发错/漏发：
    └── 立即补发 + 赠送小礼品

原则：先解决客户问题，再追究内部原因。
      绝不与客户争论。
```
