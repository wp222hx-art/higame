## 二、采后处理标准

### 2.1 采收标准

| 产品 | 成熟度指标 | 采收时间 | 采收方法 | 注意事项 |
|------|-----------|---------|---------|---------|
| 番茄 | 转色期70-80% | 早晨露干后 | 手摘带萼 | 不可雨后采收 |
| 草莓 | 全红>80% | 早晨/傍晚 | 剪刀留柄 | 轻拿轻放 |
| 葡萄 | 糖度>16° | 早晨 | 剪穗 | 不碰果霜 |
| 柑橘 | 着色>80% | 晴天 | 两剪法 | 果梗平齐 |
| 黄瓜 | 商品成熟度 | 早晨 | 手摘 | 带刺新鲜 |

### 2.2 分拣分级标准

```
通用四级分拣法：

  ┌────────────┐
  │  特级（A+） │  → 大小均匀、外观完美、无瑕疵
  │  占比 15%   │     用途：礼品装、高端电商
  ├────────────┤
  │  一级（A）  │  → 大小均匀、轻微瑕疵可接受
  │  占比 40%   │     用途：标准电商、直播
  ├────────────┤
  │  二级（B）  │  → 大小不均、有轻微伤痕
  │  占比 30%   │     用途：批发市场、团购
  ├────────────┤
  │  三级（C）  │  → 外观不佳但品质正常
  │  占比 15%   │     用途：食堂、深加工
  └────────────┘
```

## 三、仓储保鲜方案

### 3.1 冷链设施规划

```
村级冷链中心布局：

  ┌──── 预冷间 ────┐  ┌──── 分拣车间 ────┐  ┌──── 包装间 ────┐
  │ 0-5°C          │  │ 15-20°C          │  │ 15-20°C        │
  │ 快速降温        │→│ 分拣分级          │→│ 贴标包装        │
  │ 采后30分钟内    │  │ 质检称重          │  │ 一物一码        │
  └────────────────┘  └──────────────────┘  └────────────────┘
          │
          ▼
  ┌──── 冷库A ─────┐  ┌──── 冷库B ─────┐
  │ 蔬菜冷藏        │  │ 水果气调        │
  │ 2-8°C          │  │ 0-5°C, CA气调  │
  │ 容量：50吨      │  │ 容量：30吨      │
  └────────────────┘  └────────────────┘
```

### 3.2 各品类保鲜参数

| 品类 | 预冷温度 | 储存温度 | 湿度 | 保鲜期 | 技术手段 |
|------|---------|---------|------|--------|---------|
| 叶菜类 | 2-4°C | 0-2°C | 95-98% | 7-15天 | 保鲜膜+预冷 |
| 果菜类(番茄) | 10-12°C | 10-13°C | 85-90% | 15-25天 | 不宜低于10°C |
| 草莓 | 0-1°C | 0-2°C | 90-95% | 5-7天 | 预冷+气调 |
| 葡萄 | 0°C | -1~0°C | 90-95% | 30-60天 | SO₂熏蒸+冷藏 |
| 柑橘 | 5-8°C | 3-5°C | 85-90% | 60-90天 | 防腐处理+冷藏 |

## 四、物流配送方案

### 4.1 物流渠道矩阵

| 渠道 | 适用距离 | 时效 | 成本/kg | 适合品类 |
|------|---------|------|---------|---------|
| 自有车辆 | 100km内 | 当日达 | 0.3-0.5 | 批发、食堂供应 |
| 同城配送 | 同城 | 4小时 | 1-3 | 社区团购 |
| 快递(顺丰) | 全国 | 1-2天 | 5-15 | 高端水果/电商 |
| 快递(通达系) | 全国 | 2-4天 | 3-8 | 耐储存产品 |
| 冷链物流 | 全国 | 1-3天 | 8-20 | 鲜活易腐 |
| 城配物流 | 省内 | 次日达 | 1-3 | 批量配送 |

### 4.2 包装与物流匹配

```
包装设计原则：

  电商小包（1-5kg）：
  ┌────────────────────┐
  │ 泡沫箱 + 冰袋       │ ← 草莓/樱桃等娇贵水果
  │ 或 瓦楞纸箱 + 网套   │ ← 苹果/柑橘等耐运水果
  │ + 气柱袋/珍珠棉      │ ← 防震填充
  │ + 品牌封箱胶         │ ← 品牌露出
  └────────────────────┘

  批发大包（10-25kg）：
  ┌────────────────────┐
  │ 纸箱/塑料筐          │
  │ + 内衬纸             │
  │ + 分层摆放           │
  └────────────────────┘
```

## 五、损耗控制

### 5.1 各环节损耗目标

| 环节 | 当前损耗率 | 目标损耗率 | 改善措施 |
|------|-----------|-----------|---------|
| 采收 | 5-8% | <3% | 标准化采收培训 |
| 分拣 | 3-5% | <2% | 分级利用（C级→加工） |
| 仓储 | 5-10% | <3% | 冷链设施建设 |
| 物流 | 5-8% | <3% | 优化包装+冷链 |
| 终端 | 3-5% | <2% | 精准需求匹配 |
| **全链合计** | **20-35%** | **<12%** | **系统化改善** |

### 5.2 损耗挽救机制

```
损耗发生 → 立即分流处理：

  外观受损但品质正常 → 降级销售（B/C级渠道）
  轻微软化/过熟      → 深加工（果酱/果干/果汁）
  滞销库存积压       → 紧急促销/直播清仓
  不可食用          → 堆肥/沼气原料（不浪费）
```
