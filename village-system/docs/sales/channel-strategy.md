## 二、线上渠道

### 2.1 电商平台

| 平台 | 定位 | 入驻要求 | 费用 | 适合品类 |
|------|------|---------|------|---------|
| 拼多多 | 性价比、走量 | 门槛低 | 佣金0.6-3% | 大宗蔬果 |
| 淘宝/天猫 | 品牌化、品质 | 中高 | 佣金2-5% | 特色/有机产品 |
| 京东自营 | 品质保障 | 高(供货商) | 扣点8-12% | 高端水果 |
| 抖音小店 | 兴趣电商 | 中 | 佣金1-5% | 所有品类 |
| 微信小商店 | 私域流量 | 极低 | 免佣金 | 所有品类 |

**核心策略**：
- **拼多多打量** — 大宗应季产品走量冲销量
- **抖音做品牌** — 短视频+直播建立品牌认知
- **微信做私域** — 复购、会员、社区团购

### 2.2 直播带货

```
直播矩阵规划：

  日常直播（每天）          
  ┌───────────────────────┐
  │ 时间：早7-9点（田间直播）│
  │ 内容：采摘过程、农事日常  │
  │ 目的：建立信任、日常出单  │
  │ 平台：抖音              │
  └───────────────────────┘
  
  专题直播（每周2-3次）      
  ┌───────────────────────┐
  │ 时间：晚8-10点          │
  │ 内容：产品讲解、优惠活动  │
  │ 目的：集中出单、冲销量    │
  │ 平台：抖音 + 快手        │
  └───────────────────────┘
  
  大型活动（月度/节点）       
  ┌───────────────────────┐
  │ 时间：丰收季、电商节      │
  │ 内容：村长带货、联合直播   │
  │ 目的：品牌曝光、大额出单   │
  │ 平台：全平台              │
  └───────────────────────┘
```

### 2.3 社区团购

```
模式：村 → 城市社区团长 → 消费者

  每周一        → 团长发布本周可售产品清单
  每周三 18:00  → 截单
  每周四        → 采收、分拣、打包
  每周五        → 物流发出
  每周六        → 送达社区自提点

关键指标：
  - 每个团长覆盖 50-200 户
  - 目标：发展 20-50 个稳定团长
  - 复购率目标：60%+
```

## 三、线下渠道

### 3.1 批发市场

| 市场类型 | 覆盖范围 | 价格水平 | 供货量 | 结算方式 |
|---------|---------|---------|--------|---------|
| 本地农贸市场 | 县/乡 | 低 | 日供 | 现结 |
| 区域批发市场 | 地市级 | 中 | 批量 | 周结/月结 |
| 一级批发市场 | 省级 | 高 | 大批量 | 月结 |

**注意事项**：
- 批发商尽量对接2-3家，避免依赖单一批发商
- 结算周期越短越好，避免账期超过30天
- 价格谈判基于当日市场行情，`pricing-analyst` 提供实时参考

### 3.2 食堂/企业供应

```
目标客户类型：
  ┌─────────────┬──────────────┬──────────────────┐
  │ 学校食堂     │ 企业食堂      │ 机关食堂          │
  │ 需求稳定     │ 量大价优      │ 品质要求高        │
  │ 品种常规     │ 品种多样      │ 食品安全证明      │
  │ 日供        │ 日/周供       │ 日供             │
  └─────────────┴──────────────┴──────────────────┘

合同模式：季度/年度供应协议
  → 固定品种 + 浮动价格（随市场调整±10%）
  → 月结，账期不超过30天
  → 附带农残检测报告
```

### 5.2 滞销应急分流

```
滞销预警 (pricing-analyst 触发):
  │
  ├── 价格下降>20% → 启动分流
  │
  ├── 1. 直播紧急促销 → livestream-seller 安排当晚专场
  ├── 2. 社区团购降价 → ecommerce-operator 推送特价
  ├── 3. 食堂加量供应 → wholesale-expert 联系食堂客户
  ├── 4. 深加工转化   → 果酱/果干/腌制
  └── 5. 捐赠(最后手段) → 公益助农 + 品牌正面形象
```
