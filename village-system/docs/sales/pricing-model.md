# 定价模型

> 既不贱卖农产品，也不定价过高失去市场。本文档建立科学的动态定价体系。

---

## 一、定价原则

### "三看一算"定价法

```
┌──────────┐  ┌──────────┐  ┌──────────┐  ┌──────────┐
│ 看成本    │  │ 看市场    │  │ 看品质    │  │ 算利润    │
│ 底线在哪  │  │ 行情多少  │  │ 差异在哪  │  │ 目标多少  │
└─────┬────┘  └─────┬────┘  └─────┬────┘  └─────┬────┘
      │             │             │             │
      └─────────────┴─────────────┴─────────────┘
                         │
                  ┌──────▼──────┐
                  │  最终定价    │
                  └─────────────┘
```

## 二、成本核算模型

### 2.1 种植成本构成

```yaml

  土地租金:     800 元/亩/年
```

## 三、渠道差异化定价

### 3.1 基础定价公式

```
渠道终端价 = 成本价 × (1 + 目标毛利率) × 渠道加价系数

渠道加价系数：
  批发市场:   1.0 （基准价）
  电商零售:   1.5-2.0 （包含包装+运费+平台费用）
  直播带货:   1.3-1.8 （高引流低毛利换复购）
  社区团购:   1.2-1.5 （薄利多销+团长佣金）
  采摘体验:   2.0-3.0 （体验溢价）
  礼品定制:   2.5-4.0 （品牌+包装+设计溢价）
```

### 3.2 渠道定价示例（草莓）

| 渠道 | 定价(元/kg) | 定价逻辑 | 毛利率 |
|------|------------|---------|--------|
| 批发市场 | 16-20 | 随行就市 | 60-70% |
| 电商零售(500g) | 29.9-39.9 | 含包装+运费 | 40-55% |
| 直播带货(1kg) | 35.9-45.9 | 引流价+赠品 | 35-50% |
| 社区团购(1kg) | 25.9-35.9 | 性价比 | 45-60% |
| 采摘体验 | 60-80/人 | 体验+自采 | 65-80% |
| 礼品装(精选2kg) | 168-268/盒 | 品牌溢价 | 55-75% |

## 四、动态定价机制

### 4.1 价格调整触发条件

```
pricing-analyst 监控以下指标，自动触发价格调整建议：

┌─────────────────┬────────────────────────────────┐
│ 触发条件         │ 调价动作                        │
├─────────────────┼────────────────────────────────┤
│ 市场价涨幅>15%   │ 跟涨，但滞后1-2天确认趋势       │
│ 市场价跌幅>20%   │ 评估是否启动分流机制（见渠道策略） │
│ 库存>3天销量     │ 降价5-10%加速出货               │
│ 库存<1天销量     │ 提价5-10%或限购                 │
│ 竞品降价>10%    │ 评估品质差异，决定是否跟进       │
│ 节假日前7天      │ 礼品类提价10-20%                │
│ 丰收季(量大)     │ 批发价下调，电商增加促销         │
└─────────────────┴────────────────────────────────┘
```

### 4.2 价格区间管理

```
每个产品设定价格区间：

          最低价（成本×1.1）
            │
    ┌───────▼───────┐
    │   保本区间     │ ← 滞销时的底线（不亏损）
    ├───────────────┤
    │   常规区间     │ ← 市场正常时的定价区间
    ├───────────────┤
    │   溢价区间     │ ← 供不应求/品质突出时
    ├───────────────┤
    │   品牌区间     │ ← 有机认证/品牌溢价
    └───────────────┘
            │
          最高价（品牌+有机认证价）

pricing-analyst 维护每个产品的价格区间，
超出区间需 sales-director 审批。
```

## 五、促销策略

### 5.1 常用促销手段

| 手段 | 适用场景 | 让利幅度 | 效果 |
|------|---------|---------|------|
| 买一送一 | 滞销/新品推广 | 50% | ★★★★★(清货) |
| 满减(满X减Y) | 客单价提升 | 15-25% | ★★★★(提高客单) |
| 限时特价 | 直播/大促 | 20-30% | ★★★★(冲量) |
| 尝鲜价 | 新品上市 | 30-40% | ★★★(拉新) |
| 会员折扣 | 复购用户 | 10-15% | ★★★★(留存) |
| 组合装 | 提高销量 | 10-20% | ★★★(去库存) |

### 5.2 年度促销日历

| 月份 | 节点 | 促销方向 | 渠道重点 |
|------|------|---------|---------|
| 1-2月 | 春节 | 礼品装、年货节 | 电商+直播 |
| 3月 | 38女神节 | 草莓+鲜花组合 | 直播+团购 |
| 5月 | 母亲节 | 水果礼盒 | 电商+线下 |
| 6月 | 618大促 | 全品类打折 | 全渠道 |
| 8月 | 丰收前预售 | 预售新果 | 电商+直播 |
| 9-10月 | 丰收节+国庆 | 采摘+礼品+大促 | 全渠道 |
| 11月 | 双11 | 囤货装 | 电商+直播 |
| 12月 | 双12+年末 | 清库存+预售 | 全渠道 |
