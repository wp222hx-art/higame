## 二、品牌命名与定位

### 2.1 命名原则

```
好名字的标准：
  ✅ 好记 — 2-4个字，易读易写
  ✅ 有画面感 — 让人联想到田园/新鲜/绿色
  ✅ 可注册 — 不与已有商标冲突
  ✅ 延展性 — 可用于多个品类
  
命名方向：
  1. 地名型 → "XX谷""XX村""XX溪"
  2. 意象型 → "晨露""沃土""青禾"
  3. 故事型 → "阿婆的菜园""老张家"
  4. 理念型 → "本真""归田""朴实"
```

### 2.2 品牌定位

```
核心定位：「来自生态村的安心食材」

品牌价值三角：
        ┌─── 安全 ───┐
        │  有机/绿色   │
        │  全程可追溯  │
        └──────┬──────┘
               │
    ┌──────────┼──────────┐
    │                     │
┌───▼───┐          ┌─────▼───┐
│  新鲜  │          │  故事   │
│ 当日采摘│          │ 乡土情怀│
│ 冷链直达│          │ 匠心种植│
└────────┘          └─────────┘
```

## 三、视觉识别系统

### 3.1 核心元素

| 元素 | 要求 | 说明 |
|------|------|------|
| Logo | 简洁、绿色系 | 需要中英文双版本 |
| 主色调 | 绿色(#4CAF50)+土黄(#8B7355) | 自然+大地 |
| 辅助色 | 果实色系（红/橙/紫） | 按产品品类使用 |
| 字体 | 圆体（亲和力） | 不使用楷书/宋体 |
| 图形元素 | 叶片、山水、阳光 | 乡村意象 |

### 3.2 包装层级

| 层级 | 用途 | 成本(元/个) | 设计要求 |
|------|------|------------|---------|
| 基础包装 | 批发/团购 | 0.5-1 | 品牌logo+品名+产地+重量 |
| 标准包装 | 电商零售 | 2-5 | 品牌视觉+产品图+二维码溯源 |
| 精品包装 | 礼品/高端 | 10-30 | 设计感+故事卡+手提袋 |
| 节庆包装 | 春节/中秋 | 15-50 | 节日主题+组合装 |

## 四、内容营销策略

### 4.1 短视频内容矩阵

| 类型 | 频率 | 内容方向 | 目标 |
|------|------|---------|------|
| 农事日常 | 每日 | 日出、劳作、收获、田园风光 | 建立真实感 |
| 知识科普 | 每周2次 | 怎么挑水果、有机vs普通、时令知识 | 建立专业感 |
| 幕后故事 | 每周1次 | 种植者的故事、传统手艺、村庄历史 | 建立情感连接 |
| 产品展示 | 上新时 | 开箱、试吃、烹饪教程 | 促进转化 |
| 互动活动 | 每月1次 | 猜重量、取名字、投票 | 增加互动 |

### 4.2 IP人设打造

```
推荐IP类型：

  1. 「村长」IP — 朴实可信的长者形象
     ▸ 讲述村庄故事和发展理念
     ▸ 重大活动/直播压轴出场
     
  2. 「田间小妹/小哥」IP — 年轻活力的新农人
     ▸ 日常直播、短视频主力
     ▸ 展示年轻人回乡创业的故事
     
  3. 「老农」IP — 经验丰富的种植能手
     ▸ 技术科普、种植知识
     ▸ 产品品质背书
```

## 五、认证与信任体系

### 5.1 认证路径

```
第1年：绿色食品认证（A级）
  → 费用：5,000-10,000元/品类
  → 周期：3-6个月
  → 核心：农药/化肥使用符合标准

第2年：有机食品认证（部分品类）
  → 费用：10,000-30,000元/品类
  → 周期：转换期1-3年
  → 核心：全程不使用化学合成物

第3年：地理标志产品（如条件符合）
  → 费用：集体申报
  → 周期：6-12个月
  → 核心：产区+品质+历史
```
