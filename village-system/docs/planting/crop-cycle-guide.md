## 三、作物生长阶段管理要点

### 通用七阶段模型

```
播种期 → 苗期 → 营养生长期 → 开花期 → 结果/灌浆期 → 成熟期 → 采收期
  │        │         │           │          │            │         │
  ▼        ▼         ▼           ▼          ▼            ▼         ▼
基肥     追肥1     追肥2+防虫   授粉管理   追肥3+控水   停药期    质检+包装
底水     控水      灌溉调节     温度管理   防裂/防落    检测残留   冷链对接
```

### 各阶段关键指标

| 阶段 | 土壤监测 | 水分管理 | 肥料要求 | 病虫害防治 |
|------|---------|---------|---------|-----------|
| 播种期 | pH值、有机质 | 底墒充足 | 基肥（有机肥为主） | 种子处理 |
| 苗期 | 温度、湿度 | 少浇勤浇 | 薄肥勤施 | 防猝倒病 |
| 营养生长期 | NPK含量 | 正常灌溉 | 氮肥为主 | 蚜虫/螨虫 |
| 开花期 | 硼/钙/锌 | 适度控水 | 磷钾为主 | 灰霉病 |
| 结果/灌浆期 | 钾含量 | 充足灌溉 | 钾肥为主 | 果实腐烂 |
| 成熟期 | — | 控水促熟 | 停止追肥 | 停药（安全间隔期） |
| 采收期 | — | 采前控水 | — | 农残检测 |

## 四、关键农事节点提醒机制

系统通过 `/weather-alert` 和 `/seasonal-plan` 技能联动，自动生成提醒：

- **播种窗口** — 根据气温和墒情，提前7天提醒
- **施肥节点** — 根据生长阶段和土壤检测，精准推送
- **防治窗口** — 根据气象条件（温湿度），预警病虫害高发期
- **采收窗口** — 根据成熟度指标和市场行情，建议最佳采收时间
- **农残安全期** — 倒推计算最后用药时间

## 五、代理协作关系

```
village-chief (决策)
    │
    ├── planting-director (统筹) ←→ sales-director (需求反馈)
    │       │
    │       ├── soil-expert        → 土壤检测与改良建议
    │       ├── meteorologist      → 气象预报与农事窗口
    │       ├── seed-expert        → 品种推荐与种子采购
    │       ├── irrigation-engineer → 灌溉方案与水分管理
    │       ├── pest-control-expert → 病虫害预警与防治
    │       ├── machinery-expert   → 农机调度与作业安排
    │       └── harvest-expert     → 采收时机与质量把控
    │
    └── quality-director → 产品安全检测与认证
```
