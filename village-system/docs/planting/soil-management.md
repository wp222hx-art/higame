# 土壤管理手册

> 土壤是农业的根基。本手册覆盖土壤检测、改良、保护的全流程，指导 soil-expert 代理和相关人员工作。

---

## 一、土壤检测体系

### 1.1 常规检测项目

| 检测项 | 频率 | 理想范围 | 检测方法 | 代理负责 |
|--------|------|---------|---------|---------|
| pH值 | 每季 | 6.0-7.0 | 电位法 | soil-expert |
| 有机质含量 | 每年 | >2.5% | 重铬酸钾法 | soil-expert |
| 全氮 | 每年 | >0.15% | 凯氏定氮 | soil-expert |
| 速效磷 | 每季 | 15-30mg/kg | 碳酸氢钠浸提 | soil-expert |
| 速效钾 | 每季 | 80-150mg/kg | 醋酸铵浸提 | soil-expert |
| 微量元素(Ca/Mg/Fe/Zn/B) | 每年 | 因元素而异 | 原子吸收 | soil-expert |
| 重金属(Cd/Pb/As/Hg/Cr) | 2年 | GB15618标准 | ICP-MS | food-safety-inspector |
| 农残(有机氯/有机磷) | 有机地块每年 | 不得检出 | GC-MS | organic-certifier |

### 1.2 取样规范

```
取样深度：
  ┌─────────────────┐ 0cm
  │   耕作层取样     │ ← 大田作物：0-20cm
  ├─────────────────┤ 20cm
  │   亚耕层取样     │ ← 果树/深根作物：20-40cm
  ├─────────────────┤ 40cm
  │   心土层(必要时) │ ← 特殊需求：40-60cm
  └─────────────────┘ 60cm

取样方法："S"形取样法
  每个地块取 5-8 个点 → 充分混合 → 四分法取 1kg 样品
```

### 1.3 检测报告格式

```yaml
报告编号: SOIL-2026-A001-Q1
地块编号: A-001
采样日期: 2026-03-15
采样深度: 0-20cm
检测结果:
  pH: 6.2 (正常)
  有机质: 2.8% (良好)
  全氮: 0.18% (良好)
  速效磷: 12mg/kg (⚠️ 偏低)
  速效钾: 95mg/kg (正常)
  交换性钙: 1200mg/kg (正常)
  有效锌: 0.8mg/kg (⚠️ 偏低)
改良建议:
  - 增施磷肥，推荐过磷酸钙 40kg/亩
  - 补充锌肥，推荐硫酸锌 1kg/亩
  - 继续施用有机肥维持有机质含量
下次检测: 2026-06-15
```

## 二、土壤改良方案

### 2.1 酸性土壤改良（pH < 5.5）

| 改良措施 | 用量 | 效果 | 持续时间 |
|---------|------|------|---------|
| 施石灰 | 100-200kg/亩 | pH升高0.5-1.0 | 2-3年 |
| 施草木灰 | 50-100kg/亩 | pH升高0.3-0.5 | 1-2年 |
| 施白云石粉 | 80-150kg/亩 | 同时补钙镁 | 2-3年 |

**注意**：石灰不可与铵态氮肥同施，需间隔 15 天以上。

### 2.2 有机质提升

| 方法 | 年增加量 | 成本(元/亩) | 操作难度 |
|------|---------|------------|---------|
| 秸秆还田 | +0.05-0.1% | 50-80 | ★ |
| 施商品有机肥(2吨/亩) | +0.1-0.2% | 600-800 | ★★ |
| 种植翻压绿肥 | +0.2-0.5% | 100-200 | ★★ |
| 施用沼液沼渣 | +0.1-0.3% | 200-400 | ★★★ |
| 蚯蚓堆肥 | +0.3-0.5% | 800-1200 | ★★★★ |

**目标**：全村耕地有机质含量在 5 年内达到 3% 以上。

### 2.3 盐碱地改良

```
改良步骤（适用于 pH 8.0-9.0 的轻度盐碱地）：

1. 排水工程 → 降低地下水位至 1.5m 以下
2. 灌水洗盐 → 大水漫灌 2-3 次冲洗表层盐分
3. 施石膏    → 100-200kg/亩（钙离子置换钠离子）
4. 增施有机肥 → 改善土壤结构
5. 种植耐盐先锋作物 → 碱蓬/田菁/向日葵
6. 逐步过渡  → 耐盐作物 → 一般作物
```

## 三、土壤保护措施

### 3.1 防止水土流失

- **坡地**：修建梯田、等高线种植、草带护坡
- **平地**：保护性耕作（少耕/免耕）、秸秆覆盖
- **沟道**：植物护坡、建设沉沙池
- **植被**：道路两侧种植行道树，地边种植草带

### 3.2 防止土壤板结

```
✅ 正确做法：
  → 有机肥与化肥配合使用（有机肥占总施肥量60%+）
  → 适时深翻松土（每年至少1次，深度25-30cm）
  → 种植深根作物打破犁底层
  → 减少不必要的机械碾压

❌ 错误做法：
  → 长期单施化肥
  → 湿地作业（含水量过高时碾压）
  → 过度旋耕（形成犁底层）
  → 忽视有机质补充
```

### 3.3 土壤污染防治

| 污染源 | 防控措施 | 监测频率 |
|--------|---------|---------|
| 农药残留 | 使用生物农药，严格安全间隔期 | 有机地块每季 |
| 化肥过量 | 测土配方施肥，控制总量 | 每季检测EC值 |
| 重金属 | 禁用未检测的污泥/工业废料 | 2年1次 |
| 农膜残留 | 使用可降解地膜，回收旧膜 | 年度清理 |

## 四、测土配方施肥系统

### 核心公式

```
施肥量(kg/亩) = (目标产量需求量 - 土壤供给量) / 肥料利用率

其中：
  目标产量需求量 = 百公斤产量养分吸收量 × 目标亩产(百kg)
  土壤供给量 = 土壤有效养分含量 × 校正系数
  肥料利用率：氮 30-35%，磷 20-25%，钾 40-50%
```

### 示例

```
水稻目标亩产 500kg：
  需氮量 = 500/100 × 2.2 = 11kg 纯氮
  土壤供氮 = 125mg/kg × 0.04 = 5kg
  需施氮量 = (11 - 5) / 0.35 = 17.1kg 纯氮
  折合尿素 = 17.1 / 0.46 = 37.2kg
```

## 五、代理协作

| 代理 | 职责 |
|------|------|
| `soil-expert` | 检测计划、取样、数据分析、改良方案 |
| `planting-director` | 依据土壤报告调整种植方案 |
| `ecology-director` | 监督土壤保护、有机质提升目标 |
| `irrigation-engineer` | 水分管理与盐碱改良的水利配合 |
| `finance-director` | 土壤改良预算审批 |

## 六、关联技能

- `/soil-analysis` — 启动土壤检测与分析
- `/fertilizer-plan` — 基于检测结果的配方施肥方案
- `/crop-plan` — 考虑土壤条件的种植方案
