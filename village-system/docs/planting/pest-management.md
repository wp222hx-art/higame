# 病虫害综合管理手册

> 预防为主、综合防治。本手册建立从监测预警到应急响应的完整病虫害管理体系。

---

## 一、管理原则

### "四步防治法"

```
┌──────────┐    ┌──────────┐    ┌──────────┐    ┌──────────┐
│ 1. 预防   │ →  │ 2. 监测   │ →  │ 3. 预警   │ →  │ 4. 防治   │
│ 农业防治  │    │ 定期巡查  │    │ 系统推送  │    │ 精准用药  │
│ 生态调控  │    │ 数据采集  │    │ 风险评估  │    │ 绿色防控  │
└──────────┘    └──────────┘    └──────────┘    └──────────┘
```

### 防治优先级

1. **农业防治（首选）** — 轮作、选用抗病品种、清洁田园
2. **物理防治** — 灯诱、色板、防虫网、覆膜
3. **生物防治** — 天敌释放、生物农药（苏云金杆菌、阿维菌素）
4. **化学防治（最后手段）** — 低毒低残留农药，严格安全间隔期

## 二、主要病害防控

### 2.1 常见病害一览

| 病害 | 危害作物 | 发病条件 | 典型症状 | 防控方案 |
|------|---------|---------|---------|---------|
| 稻瘟病 | 水稻 | 高温高湿、偏施氮肥 | 叶片梭形褐斑 | 三环唑预防 + 抗病品种 |
| 番茄晚疫病 | 番茄、马铃薯 | 低温高湿(15-20°C) | 叶缘水渍状暗绿斑 | 甲霜灵 + 通风降湿 |
| 灰霉病 | 草莓、番茄 | 低温潮湿 | 灰色霉层覆盖 | 腐霉利 + 控湿 |
| 枯萎病 | 西瓜、黄瓜 | 连作、土壤带菌 | 萎蔫不恢复 | 嫁接 + 轮作 + 土壤消毒 |
| 白粉病 | 瓜类、草莓 | 干燥通风差 | 白色粉状物 | 硫磺制剂 + 通风 |
| 疫病(根腐) | 辣椒、茄子 | 积水、高温 | 根基褐变腐烂 | 排水 + 铜制剂 |

### 2.2 病害预警模型

```python
# pest-control-expert 使用的预警逻辑
def disease_risk_assessment(crop, weather_forecast):
    risk_score = 0
    
    # 温度评估
    if crop == "水稻" and weather["temp"] > 25 and weather["humidity"] > 85:
        risk_score += 3  # 稻瘟病高风险
    
    # 连续阴雨
    if weather["rainy_days_consecutive"] >= 3:
        risk_score += 2  # 灰霉病/晚疫病风险
    
    # 连作年限
    if field["continuous_years"] > allowed_max[crop]:
        risk_score += 3  # 土传病害高风险
    
    # 风险等级
    if risk_score >= 5: return "🔴 高风险 — 立即防治"
    if risk_score >= 3: return "🟡 中风险 — 预防用药"
    return "🟢 低风险 — 继续监测"
```

## 四、安全用药规范

### 4.1 农药使用基本准则

1. **先诊断后用药** — 确认病虫种类再选药，不盲目混配
2. **对症选药** — 杀虫剂、杀菌剂、除草剂不混用
3. **适时用药** — 防治适期（害虫低龄期、发病初期）
4. **适量用药** — 严格按标签推荐用量，不加量
5. **安全间隔** — 采收前必须保证安全间隔期

### 4.2 安全间隔期速查表

| 农药 | 用途 | 安全间隔期 | 施用次数上限 |
|------|------|-----------|------------|
| 吡虫啉 | 蚜虫/飞虱 | 7天 | 3次 |
| 阿维菌素 | 螨类/线虫 | 7天 | 2次 |
| 三环唑 | 稻瘟病 | 21天 | 2次 |
| 甲霜灵 | 疫病 | 14天 | 3次 |
| 腐霉利 | 灰霉病 | 7天 | 3次 |
| 苏云金杆菌(Bt) | 鳞翅目 | 无(生物农药) | 不限 |
| 矿物油 | 介壳虫/螨 | 无(物理防治) | 不限 |

### 4.3 禁用农药清单

以下农药**严禁在村内使用**：

```
🚫 甲胺磷、甲基对硫磷、对硫磷、氧化乐果（已禁用高毒有机磷）
🚫 克百威（呋喃丹）、涕灭威（高毒氨基甲酸酯）
🚫 水胺硫磷、灭线磷
🚫 内吸磷、百治磷
🚫 任何未获得农药登记证的产品
```

## 五、应急响应机制

### 5.1 响应等级

| 等级 | 触发条件 | 响应措施 | 牵头代理 |
|------|---------|---------|---------|
| 🟢 一般 | 零星发生，点片为主 | 常规巡查，局部防治 | pest-control-expert |
| 🟡 警戒 | 扩散趋势，多地块发生 | 加密监测，预防用药 | planting-director |
| 🔴 紧急 | 大面积爆发，损失>10% | 全村统防统治 | village-chief |

### 5.2 统防统治流程

```
发现疫情 → pest-control-expert 诊断
    │
    ├── 确认种类和范围
    ├── 制定用药方案（药剂+浓度+方法）
    ├── planting-director 审批
    │
    ├── machinery-expert 调度植保无人机/喷药机
    ├── logistics-director 紧急采购农药
    │
    ├── 统一施药（2天内完成）
    └── 跟踪效果（3天后复查）
```
