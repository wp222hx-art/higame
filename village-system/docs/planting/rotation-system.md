# 轮作制度

> 科学轮作是可持续农业的基石。本文档规定全村的轮作规则、周期安排和地力恢复方案。

---

## 一、轮作的核心原理

### 为什么必须轮作？

1. **养分均衡** — 不同作物消耗不同元素，轮作避免单一元素耗竭
2. **病虫害截断** — 换茬切断病虫害的连续繁殖周期
3. **土壤结构改良** — 深根作物 → 浅根作物 → 豆科固氮，层层改善
4. **产量稳定** — 连作导致产量逐年下降（连作障碍）

### 连作危害等级

| 等级 | 作物 | 连作后果 | 最大连作年限 |
|------|------|---------|------------|
| 🔴 严禁连作 | 番茄、辣椒、茄子（茄科） | 枯萎病、青枯病爆发 | 1年 |
| 🔴 严禁连作 | 西瓜、甜瓜（葫芦科） | 蔓枯病、产量骤降 | 1年 |
| 🟡 不宜连作 | 白菜、萝卜（十字花科） | 根肿病、软腐病 | 2年 |
| 🟡 不宜连作 | 草莓 | 根腐病、灰霉病 | 2年 |
| 🟢 可短期连作 | 水稻 | 土壤退化缓慢 | 3年（需间种绿肥） |
| 🟢 可短期连作 | 玉米 | 产量缓慢下降 | 2-3年 |

## 二、推荐轮作模式

### 模式 A：水旱轮作（南方水田区）

```
第1年：早稻 → 晚稻
第2年：油菜（冬）→ 水稻（夏）
第3年：绿肥（紫云英）→ 水稻
第4年：回到第1年
```

**优点**：水旱交替改善土壤通透性，油菜/绿肥增加有机质  
**亩均增产**：15-20%（与连续双季稻相比）

### 模式 B：粮经轮作（旱地区）

```
第1年：春玉米 → 秋白菜
第2年：番茄（春夏）→ 萝卜（秋冬）
第3年：大豆（固氮）→ 冬小麦
第4年：回到第1年
```

**优点**：经济作物提高收益，大豆固氮恢复地力  
**收益对比**：纯粮食轮作的 2-3 倍

### 模式 C：果蔬套种

```
果树行间（年幼果园 1-3 年）：
春：矮生蔬菜（生菜、菠菜）
夏：豆科（绿豆、花生）
秋：十字花科（小白菜）
冬：绿肥（苕子、紫云英）

果树盛果期（第4年+）：
行间种植耐阴草本或放弃间作
```

**优点**：幼龄果园的土地利用率提高 60%

### 模式 D：设施大棚轮作

```
第1年 春夏：番茄 → 秋冬：草莓
第2年 春夏：黄瓜 → 秋冬：草莓
第3年 春夏：辣椒 → 秋冬：叶菜（生菜、芹菜）
第4年 春季休棚+土壤消毒+种植绿肥 → 秋冬回到第1年
```

**重点**：大棚每 3-4 年必须有一个休棚消毒期

## 三、地块管理台账

### 地块档案格式

每个地块必须建立电子档案，包含：

```yaml
地块编号: A-001
面积: 3.5亩
地形: 平地
土壤类型: 黄壤
排灌条件: 有灌有排
前3年种植记录:
  - 2024年: 早稻+晚稻
  - 2025年: 油菜+水稻
  - 2026年: 绿肥+水稻（规划中）
当前土壤状态:
  pH: 6.2
  有机质: 2.8%
  速效氮: 125mg/kg
  速效磷: 18mg/kg
  速效钾: 95mg/kg
下一茬推荐: 大豆（固氮恢复）
```

### 轮作合规检查 (Hook)

系统通过 `validate-crop-plan` hook 自动检查：

- ❌ 同一地块连续种植茄科作物 → **阻断**
- ⚠️ 同一地块连续3年种植水稻 → **警告**
- ✅ 前茬为豆科，后茬为需氮作物 → **推荐**

## 四、土地休养与恢复

### 绿肥种植方案

| 绿肥作物 | 播种期 | 翻压期 | 固氮量(kg/亩) | 有机质增加 |
|---------|--------|--------|-------------|-----------|
| 紫云英 | 9-10月 | 次年3月 | 8-12 | +0.3-0.5% |
| 苕子 | 9-10月 | 次年3-4月 | 6-10 | +0.2-0.4% |
| 田菁 | 5-6月 | 7-8月 | 10-15 | +0.3-0.5% |
| 箭筈豌豆 | 10-11月 | 次年3月 | 5-8 | +0.2-0.3% |

### 土壤改良日程

```
休耕年安排：
月份 1-2  ：深翻（30cm+），施石灰调酸（如需要）
月份 3-5  ：种植春季绿肥（田菁/大豆）
月份 6    ：翻压绿肥 + 施有机肥 (2000kg/亩)
月份 7-8  ：高温闷棚消毒（大棚地块）
月份 9-10 ：种植秋季绿肥（紫云英）
月份 11-12：土壤检测，制定来年恢复计划
```

## 五、代理协作

| 代理 | 在轮作中的角色 |
|------|-------------|
| `planting-director` | 制定全村轮作总体方案 |
| `soil-expert` | 检测土壤，评估地力状态 |
| `seed-expert` | 推荐适合轮作序列的品种 |
| `pest-control-expert` | 评估连作病虫害风险 |
| `ecology-director` | 监督可持续性，推动绿肥种植 |
| `land-planner` | 地块档案管理与空间规划 |

## 六、关联技能

- `/rotation-plan` — 生成轮作方案
- `/soil-analysis` — 地力检测与评估
- `/crop-plan` — 年度种植计划（必须通过轮作检查）
