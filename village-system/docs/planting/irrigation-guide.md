# 灌溉管理指南

> 水是农业的命脉。本指南覆盖灌溉方式选择、水分管理策略和节水技术方案。

---

## 一、灌溉方式选型

### 各方式对比

| 灌溉方式 | 适用场景 | 水利用率 | 初始投资(元/亩) | 运行成本 | 适合作物 |
|---------|---------|---------|----------------|---------|---------|
| 大水漫灌 | 水稻田 | 30-40% | 极低 | 高水耗 | 水稻 |
| 沟灌 | 旱地行作物 | 50-60% | 低 | 中 | 玉米、蔬菜 |
| 喷灌 | 大面积旱作 | 70-80% | 800-1200 | 中 | 小麦、牧草 |
| 微喷 | 果园、大棚 | 80-85% | 1000-1500 | 低 | 果树、蔬菜 |
| 滴灌 | 经济作物 | 90-95% | 1500-2500 | 低 | 果树、大棚蔬菜 |
| 膜下滴灌 | 高价值作物 | 95%+ | 2000-3000 | 极低 | 草莓、番茄 |

### 推荐方案

```
大田粮食作物：
  水稻 → 浅水灌溉（间歇灌溉法）
  旱作 → 沟灌 / 低成本喷灌

经济作物（蔬菜）：
  露地 → 微喷 / 沟灌
  大棚 → 滴灌 / 膜下滴灌

果树：
  幼龄期 → 穴灌 / 滴灌
  盛果期 → 微喷 / 小管出流
```

## 二、作物需水规律

### 2.1 水稻灌溉制度

```
浅水灌溉法（节水 30%+）：

  移栽期     分蘖期      拔节孕穗期    抽穗扬花期    灌浆期     成熟期
  ┌───┐    ┌───────┐    ┌───────┐    ┌───────┐   ┌───────┐   ┌───┐
  │3-5cm│→ │浅水促蘖│→  │复水3-5cm│→ │保持3-5cm│→ │干湿交替│→ │断水│
  │浅水 │   │→晒田控│    │深水护胎 │   │保花保穗 │  │促灌浆  │   │    │
  └───┘    └───────┘    └───────┘    └───────┘   └───────┘   └───┘
                │
           够苗晒田
           (茎蘖数达目标80%时)
```

### 2.2 蔬菜灌溉要点

| 作物 | 需水关键期 | 灌溉频率 | 每次灌量 | 注意事项 |
|------|-----------|---------|---------|---------|
| 番茄 | 开花坐果期 | 3-5天/次 | 20-30m³/亩 | 果期控水防裂果 |
| 黄瓜 | 全程需水大 | 2-3天/次 | 25-35m³/亩 | 忌中午浇灌 |
| 辣椒 | 开花-结果期 | 4-6天/次 | 15-25m³/亩 | 忌积水 |
| 草莓 | 花期-果期 | 2-3天/次 | 15-20m³/亩 | 膜下滴灌最佳 |
| 白菜 | 莲座-包心期 | 3-5天/次 | 25-35m³/亩 | 包心后控水 |

### 2.3 果树灌溉要点

| 物候期 | 需水程度 | 灌溉策略 | 说明 |
|--------|---------|---------|------|
| 萌芽期 | ★★★★ | 充分灌溉 | 保证萌芽整齐 |
| 花期 | ★★ | 适度控水 | 促进坐果 |
| 幼果膨大期 | ★★★★★ | 充足灌溉 | 决定果实大小 |
| 果实转色期 | ★★ | 控水增糖 | 提高品质 |
| 采收前 | ★ | 停灌 | 利于储运 |
| 采后-落叶 | ★★★ | 秋灌保墒 | 保护根系越冬 |

## 三、节水技术方案

### 3.1 水肥一体化

```
系统组成：

  水源 → 过滤器 → 施肥器 → 主管 → 支管 → 毛管(滴头)
               │
          ┌────┴────┐
          │ 文丘里   │ ← 液体肥料桶
          │ 施肥器   │   (水溶肥按比例注入)
          └─────────┘

效果：
  ✅ 节水 40-50%
  ✅ 节肥 30-40%
  ✅ 省工 60%
  ✅ 增产 10-20%
```

### 3.2 智能灌溉控制

```
传感器网络（每个管理单元）：
  ┌──────────────┐
  │ 土壤湿度传感器 │ → 实时监测根区含水量
  │ 气象站        │ → ET0蒸散量计算
  │ 流量计        │ → 用水量统计
  └──────┬───────┘
         │
    ┌────▼─────┐
    │ 控制中心  │ → irrigation-engineer 代理分析
    └────┬─────┘
         │
    ┌────▼─────┐
    │ 电磁阀   │ → 自动启停灌溉
    └──────────┘
    
灌溉决策逻辑：
  IF 土壤湿度 < 下限阈值 AND 未来24h无降雨
    → 启动灌溉
  ELIF 土壤湿度 > 上限阈值
    → 停止灌溉
  ELIF 预报降雨 > 10mm/24h
    → 延迟灌溉
```

## 四、水源管理

### 4.1 水源类型与优先级

| 优先级 | 水源 | 水质要求 | 管理措施 |
|--------|------|---------|---------|
| 1 | 自流灌溉（河渠） | pH 6.5-8.5 | 渠道清淤、防渗 |
| 2 | 水库/塘堰 | 定期检测 | 蓄水管理、防污 |
| 3 | 地下水（井灌） | 矿化度<2g/L | 控制抽采量 |
| 4 | 雨水收集 | 初期弃流 | 建设蓄水池 |

### 4.2 用水量估算

```
全年灌溉用水量估算（100亩示例）：

  水稻 50亩 × 600m³/亩     = 30,000 m³
  蔬菜 30亩 × 300m³/亩     =  9,000 m³
  果树 20亩 × 200m³/亩     =  4,000 m³
  ──────────────────────────────────
  合计                      = 43,000 m³
  节水灌溉后(省30%)         ≈ 30,000 m³
```
