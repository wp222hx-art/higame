## 五、代理协作

| 代理 | 职责 |
|------|------|
| `finance-director` | 预算编制总负责 |
| `accountant` | 数据填写与核对 |
| `cost-analyst` | 成本核算与盈亏分析 |
| `各部门负责人` | 提交部门预算需求 |
| `village-chief` | 最终审批 |

## 六、关联技能

- `/budget-review` — 预算评审流程
