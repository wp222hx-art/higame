## 二、土地资源分配

### 2.1 分配原则

```
土地分配优先级：

  1. 保粮食安全 → 基本农田不少于总面积的40%
  2. 保经济作物 → 蔬菜/水果 30-40%
  3. 保设施用地 → 冷库/加工/道路 10%
  4. 预留发展用地 → 新项目/试验 5-10%
```

## 三、资金分配

### 3.1 年度预算分配框架

| 类别 | 占比 | 说明 |
|------|------|------|
| 种植投入 | 35-40% | 种子、肥料、农药、地膜、人工 |
| 销售费用 | 15-20% | 包装、物流、电商推广、直播 |
| 设施维护 | 10-15% | 冷链、灌溉、大棚维修 |
| 新项目投资 | 10-15% | 新品种、新设施、新渠道 |
| 管理运营 | 5-10% | 日常运营、培训、保险 |
| 应急储备 | 5-10% | 灾害应对、市场波动缓冲 |

### 3.2 资金审批流程

```
支出类型        →  审批权限

<1,000元 日常支出  →  专业代理自主决定
1,000-5,000元     →  部门负责人审批
5,000-20,000元    →  operations-director 审批
20,000-50,000元   →  village-chief 审批
>50,000元         →  village-chief + 村民代表会议

紧急支出（灾害/抢收）：
  先执行，后补审（48小时内补办手续）
  单次上限 10,000元
```

### 3.3 收益分配

```
收入分配模型：

  总销售收入
       │
       ├── 扣除直接成本（种子、肥料、人工等）
       │
       ├── 扣除运营费用（物流、包装、平台费用）
       │
       ├── 扣除管理费（集体提留 5-10%）
       │       │
       │       ├── 公共设施维护
       │       ├── 发展基金
       │       └── 应急储备
       │
       └── 净利润分配
               │
               ├── 种植户分配 60-70%（按贡献）
               ├── 管理/运营团队 15-20%
               └── 村集体发展基金 10-15%
```

## 四、劳动力调配

### 4.1 用工模式

| 模式 | 适用场景 | 用工方式 | 成本 |
|------|---------|---------|------|
| 常年用工 | 核心管理岗位 | 月薪制 | 3000-5000/月 |
| 季节性用工 | 播种/采收高峰 | 日薪制 | 100-200/天 |
| 临时用工 | 紧急抢收/抢种 | 日薪制(加价) | 150-250/天 |
| 互助用工 | 邻里互助 | 换工/免费 | 无现金成本 |
| 机械替代 | 重复性劳动 | 按亩收费 | 50-200/亩 |

## 五、农机设备调度

### 5.1 设备清单与调度

| 设备 | 数量 | 使用季节 | 调度方式 |
|------|------|---------|---------|
| 旋耕机 | — | 春秋 | machinery-expert 统一调度 |
| 插秧机 | — | 春季 | 预约制，按地块排期 |
| 收割机 | — | 夏秋 | 预约制，按成熟度排期 |
| 植保无人机 | — | 全年 | 统防统治时集中使用 |
| 运输车 | — | 全年 | 采收/出货时优先调度 |
| 冷藏车 | — | 全年 | 出货时优先调度 |

### 5.2 设备共享机制

```
村内共享：
  集体设备 → 各户按面积/需求预约
  个人设备 → 自愿加入共享池，使用有偿

跨村合作：
  与邻村/合作社共享大型设备
  → 降低单位使用成本
  → machinery-expert 负责对外协调
```
