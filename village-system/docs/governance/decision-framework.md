# 决策框架

> 从拍脑袋到用数据说话——建立科学、透明、高效的村级决策机制。

---

## 一、决策分类与权限

### 1.1 决策等级

| 等级 | 类型 | 示例 | 决策人 | 时限 |
|------|------|------|--------|------|
| S级 | 战略方向 | 产业定位、重大投资(>10万)、土地流转 | village-chief + 全村表决 | 7-14天 |
| A级 | 跨部门 | 新品种引进、新渠道开拓、设施建设 | village-chief | 3-7天 |
| B级 | 部门内 | 肥料选型、包装方案、直播排期 | 部门负责人 | 1-3天 |
| C级 | 日常执行 | 灌溉调整、价格微调、物流选择 | 专业代理 | 即时 |

### 1.2 权限矩阵

```
                    village-chief  agri-tech   operations  部门负责人  专业人员
战略方向              审批         建议        建议        —          —
年度预算(>5万)        审批         建议        编制        建议        —
新品种/技术引进        审批         审批        知会        建议        建议
季度种植调整           知会         审批        审批        执行        建议
日常采购(<5000元)     —            —          审批        审批        申请
技术方案               知会         审批        知会        执行        建议
价格调整(>10%)        审批         —          知会        建议        执行
应急响应               知会         指挥        协调        执行        执行
```

## 二、决策流程

### 2.1 标准决策流程

```
┌──────────┐
│ 1. 提议  │ ← 任何代理/村民可发起
└────┬─────┘
     │
┌────▼─────┐
│ 2. 调研  │ ← 相关代理收集数据、分析可行性
└────┬─────┘
     │
┌────▼─────┐
│ 3. 方案  │ ← 提出2-3个方案，含优劣分析
└────┬─────┘
     │
┌────▼─────┐
│ 4. 评审  │ ← 相关部门会商，发表意见
└────┬─────┘
     │
┌────▼─────┐
│ 5. 决策  │ ← 决策人做出最终选择
└────┬─────┘
     │
┌────▼─────┐
│ 6. 执行  │ ← 责任到人，时间节点明确
└────┬─────┘
     │
┌────▼─────┐
│ 7. 复盘  │ ← 效果评估，经验归档
└──────────┘
```

### 2.2 应急决策流程（简化版）

```
紧急事件发生
    │
    ├── pest-control-expert / meteorologist 确认严重程度
    │
    ├── 如等级≤B级 → planting-director 立即决策
    │
    └── 如等级≥A级 → village-chief 紧急会商（2小时内）
         │
         ├── 临时措施立即执行
         └── 后续方案24小时内确定
```

## 三、决策评估工具

### 3.1 五柱检验法

每个重大决策必须通过五大发展支柱检验：

```
决策方案：________________

  因地制宜   □ 是  □ 否  □ 不适用
    → 是否符合本地土壤/气候/水源条件？
    → 有没有同类成功案例参考？

  产销一体   □ 是  □ 否  □ 不适用
    → 生产出来卖给谁？渠道确认了吗？
    → 预期售价和成本计算过吗？

  可持续发展  □ 是  □ 否  □ 不适用
    → 3年后对土地有什么影响？
    → 生态环境有负面影响吗？

  集体利益   □ 是  □ 否  □ 不适用
    → 受益面有多广？是否公平？
    → 对没有参与的村民有影响吗？

  数据驱动   □ 是  □ 否  □ 不适用
    → 有数据支持还是凭感觉？
    → 不确定性有多大？风险可控吗？

通过条件：5项中至少4项为"是"或"不适用"
```

### 3.2 投入产出分析模板

```yaml
方案名称: _______________
投入分析:
  一次性投入: ___万元
    - 设施/设备: ___万元
    - 材料/种苗: ___万元
    - 其他: ___万元
  年度运营成本: ___万元
    - 人工: ___万元
    - 物料: ___万元
    - 其他: ___万元
  
产出分析:
  预期年产值: ___万元
  预期年利润: ___万元
  投资回收期: ___年
  
风险评估:
  最坏情况(亏损): ___万元
  最好情况(盈利): ___万元
  最可能情况: ___万元
  
对比基准:
  如果不做这件事: ___万元(保持现状收益)
  机会成本: ___万元(把同样的钱投到别处)
```

## 四、会议制度

### 4.1 会议类型

| 会议 | 频率 | 参与者 | 时长 | 产出 |
|------|------|--------|------|------|
| 晨会 | 每日 | 当班人员+operations-director | 15分钟 | 当日任务确认 |
| 周例会 | 每周 | 部门负责人 | 1小时 | 周报+问题解决 |
| 月度总结 | 每月 | 全体管理层 | 2小时 | 月报+计划调整 |
| 季度规划 | 每季 | 全体管理层+village-chief | 半天 | 季度方案定稿 |
| 年度规划 | 每年 | 全村相关方 | 1天 | 年度计划 |

### 4.2 会议记录规范

```yaml
会议记录:
  时间: 2026-03-27 09:00
  主题: ________________
  参与: [代理/人员列表]
  
讨论要点:
  1. ________________
  2. ________________
  
决议:
  1. 事项: ___  负责人: ___  截止日: ___
  2. 事项: ___  负责人: ___  截止日: ___
  
遗留问题:
  1. ________________ → 提交至___决策
```

## 五、代理协作

| 代理 | 决策框架中的角色 |
|------|----------------|
| `village-chief` | S/A级决策最终审批 |
| `agri-tech-director` | 技术可行性评估 |
| `operations-director` | 运营可行性评估、资源协调 |
| `finance-director` | 投入产出分析、预算审批 |
| `各部门负责人` | 领域专业建议 |
