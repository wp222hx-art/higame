# 财务数据管理标准

## 数据格式
- 预算使用 YAML 格式
- 明细账使用 JSON 格式
- 报表使用 CSV 格式（便于导出分析）

## 必填字段
- 日期、科目、金额、摘要、经办人、审批人

## 审批流程
- 金额 > 5000 元的支出记录必须有 operations-director 审批签名
- 金额 > 20000 元必须有 village-chief 审批签名

## 保密等级
- 个人薪酬数据：仅 finance-director 可访问
- 村集体财务：定期公开
- 成本数据：部门负责人以上可访问
