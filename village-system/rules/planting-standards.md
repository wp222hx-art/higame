# 种植数据管理标准

## 文件命名
- 使用小写字母、数字、下划线和连字符
- 格式：`{地块编号}_{作物}_{日期}.{ext}`
- 示例：`a001_tomato_2026-03-27.json`

## 数据格式
- 种植记录使用 JSON 格式
- 必须包含字段：地块编号、作物名称、品种、面积、种植日期
- 日期统一使用 `YYYY-MM-DD` 格式
- 数量单位：面积(亩)、重量(kg)、金额(元)

## 轮作检查
- 新种植计划必须标注前茬作物
- 茄科作物不可连作（系统自动检查）
- 同一地块连续3年种植同一作物需警告

## 禁止事项
- 不可在种植数据中硬编码价格信息
- 不可省略地块编号
- 不可使用非标准计量单位
