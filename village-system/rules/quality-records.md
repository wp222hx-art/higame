# 质量检测记录标准

## 检测报告格式
- 使用 JSON 格式，遵循食品安全检测报告模板
- 必须包含：样品编号、产品名称、采样日期、检测项目、检测结果、判定结论

## 农残检测
- 结果必须标注对应的 GB2763 限量标准值
- 超标项必须红色标记并触发阻断
- 合格证照片必须保留原始分辨率

## 有机认证
- 有机检测必须单独存放在 `data/quality/organic/` 目录
- 认证证书扫描件统一命名：`cert_{产品}_{有效期}.pdf`

## 数据保留
- 检测报告至少保留 3 年
- 不合格报告永久保留
