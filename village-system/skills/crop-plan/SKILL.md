# 年度种植方案规划

## 工作流

### 1. 数据收集（静默）
- 读取 `data/soil/` 各地块土壤检测报告
- 读取 `data/climate/` 历史气候数据和预报
- 读取 `data/market/` 市场行情和价格趋势
- 读取 `plans/previous-year/` 上年种植情况和收益

### 2. 现状评估
向用户报告：
- 可用土地面积和各地块条件
- 上年各作物的种植面积、产量、收益
- 当前市场热门品类和价格预测
- 劳动力和农机可用情况

### 3. 方案制定
提供 2-3 套种植方案，每套包含：
- **品种组合** — 主打品种 + 搭配品种
- **面积分配** — 各品种占多少亩
- **地块安排** — 哪块地种什么（考虑轮作）
- **时间规划** — 播种、管理、采收的关键节点
- **预期产量** — 基于历史数据的产量估算
- **预期收益** — 产量 × 预期价格 - 成本
- **风险评估** — 天气、病虫害、市场风险

### 4. 方案对比
制作对比表：

| 指标 | 方案A (稳健型) | 方案B (增长型) | 方案C (创新型) |
|------|---------------|---------------|---------------|
| 主打作物 | | | |
| 预期总收益 | | | |
| 投入成本 | | | |
| 风险等级 | | | |
| 轮作合规 | | | |

### 5. 确认执行
用户选定方案后，输出：
- 详细种植日历
- 各地块种植任务清单
- 农资采购清单（种子、肥料、农药）
- 劳动力安排表
