# 轮作倒茬规划

## 工作流

### 1. 读取地块历史
- 每块地过去 3 年种了什么
- 土壤检测变化趋势
- 病虫害发生记录

### 2. 应用轮作规则
- **禾本科-豆科交替** — 大豆/花生后接玉米/水稻
- **深根-浅根交替** — 红薯后接叶菜
- **重茬禁忌** — 茄科连作 ≤ 2年、十字花科连作 ≤ 1年
- **绿肥插入** — 空闲期种植紫云英/苕子改良土壤

### 3. 输出轮作方案
- 各地块下季推荐作物（首选 + 备选）
- 轮作原因说明
- 如需打破规则的特殊说明
