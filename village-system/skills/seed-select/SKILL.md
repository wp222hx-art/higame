# 品种筛选推荐

## 工作流

### 1. 明确需求
- 种什么类型的作物？（蔬菜/水果/粮食/经济作物）
- 地块条件？（土质、海拔、光照、水源）
- 市场定位？（批发走量 vs 精品高价）

### 2. 品种对比
为每个候选品种评估：
- 产量潜力（亩产范围）
- 抗性表现（抗病、抗旱、抗寒）
- 品质特点（口感、外观、耐储运）
- 市场接受度（消费者偏好、渠道商要求）
- 种植难度（技术要求、管理复杂度）
- 成本（种子价格、专用农资需求）

### 3. 推荐方案
输出品种推荐报告，包含：
- 主推品种 1-2 个（附详细理由）
- 搭配品种 1-2 个（分散风险）
- 试验品种 1 个（小面积尝新）
- 淘汰品种（不再推荐的原因）
